# Accessibility and Performance

Use semantic landmarks, one clear page heading, keyboard-accessible controls, visible focus states, labels for fields, meaningful button names, sufficient contrast, and text alternatives for informative images. Validate responsive behavior mobile-first across authenticated and admin views.

Indexable marketing content should be server-rendered and use Metadata API, canonical URLs, Open Graph/Twitter metadata, JSON-LD, `robots.txt`, `sitemap.xml`, and accurate `llms.txt`. Target LCP below 2.5 seconds, CLS below 0.1, and INP below 200ms. Use `next/image` and `next/font` where appropriate, avoid unnecessary client JavaScript, and measure with Lighthouse/field telemetry before claiming compliance.
